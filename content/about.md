## 关于这个站点

整个站点是手写的，没有用任何重型框架：

| 层次 | 技术选型 | 说明 |
| --- | --- | --- |
| 后端 | Go 标准库 `net/http` | 路由用 1.22+ 的 `ServeMux` 模式匹配 |
| 数据库 | SQLite（`modernc.org/sqlite`） | 纯 Go 驱动，无需 CGO，编译即用 |
| 模板 | `html/template` | 自动转义，安全可靠 |
| 渲染 | `goldmark` | 服务端渲染 Markdown，首屏直出 |
| 样式 | 手写 CSS | 无预处理器，深色优先 |

## 一些设计取舍

### 为什么不用 Web 框架

博客的路由不超过十条，标准库完全够用。少一层抽象，就少一层调试成本。

### 为什么用 SQLite

个人博客的读写量很小，SQLite 的性能绰绰有余。而且它是**一个文件**，备份就是复制一个文件。

### 为什么服务端渲染 Markdown

- 首屏直出，没有白屏
- 对搜索引擎友好
- 不需要给客户端塞一个几百 KB 的解析库

关于 MCP

开启后，支持 MCP（Model Context Protocol）的 AI 客户端可以通过 POST /mcp 读取、新增与编辑本站文章。服务与后台共用同一个数据库， 写入后前台立即生效。

可用工具：create_post（新增）、update_post（按 ID 编辑）、 list_posts（列出）、get_post（读取全文）。

客户端配置

以 Claude Code 为例，把下面这段放进 .mcp.json（或对应客户端的配置文件）即可。 把 路径 换成你的站点地址。 

{
  "mcpServers": {
    "blog": {
      "type": "http",
      "url": "https://你的域名/mcp",
      "headers": {
        "Authorization": "Bearer {{.Token}}"
      }
    }
  }
}
